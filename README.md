# Enigma_Cipher
\nAn Enigma Machine Emulator engine, mimicking the exact functionality of three WW2-era enigma machines
\n
\nThis app was made as a fun learning project to teach encryption concepts, code analysis, logic, Python OOP, and the functionality of a WW2 enigma machine
\n
\nThis app guides the user through the configuration, setup, and the encryption process of the enigma machine.
\n
User guide:
\nStep 1: Choose between 3 different enigma machines (1: Service Enigma, 2: Enigma K, 3: Railway Enigma)
\nStep 2: Choose between 3-5 rotors, each with different lettering configurations
\nStep 3: Choose reflector type
\nStep 4: Enter number of plugs to be used in plugboard (0-13)
\nStep 5: If plugs were chosen, user will be prompted to choose sockets for each plug, else step will be skipped
\nStep 6: Enter text for encryption
\n
\nPrinted numbers will show each step of the rotors throughout encryption process
\nFinal printout shows encrypted/decrypted text
